# Portfolio Skill

Build a site that could only belong to this person or this product: one clear idea, specific copy, motion with a reason, pages that search engines and assistants can read.

## Pick the mode

| The site is about | Mode | Read |
| --- | --- | --- |
| A person: developer, designer, researcher, creative, founder, student | Portfolio | [references/portfolio.md](references/portfolio.md) |
| One product: app, tool, library, service | Flagship product site | [references/product-site.md](references/product-site.md) |

Not covered: dashboards, e-commerce, app interfaces.

## Workflow

1. **Read what exists.** Files, repo, resume, README, old site, links. Never ask what these already answer.
2. **Interview.** At most five questions, one at a time: [references/interview.md](references/interview.md).
3. **Write the design brief** (template in [references/design-motion.md](references/design-motion.md)) and **wait for the user to approve it before any UI code.**
4. **Build** with [references/ship.md](references/ship.md) for the stack and [references/design-motion.md](references/design-motion.md) for type, layout and motion. Content first, then layout, then motion.
5. **Search readiness:** [references/search.md](references/search.md).
6. **Verify** in a real browser using the checklist in [references/ship.md](references/ship.md).
7. **Report** what was built, what was verified and what was not.

## Quality bar

1. **One art direction** drives type, color, layout, motion and tone.
2. **Only real content.** No invented metrics, testimonials, reviews or customers. No proof means no section.
3. **The user's taste wins** over every example in these files. No example is a default.
4. **Readable without JavaScript.** The main text of every page is in the HTML.
5. **Works from 360px to ultrawide,** by keyboard, at WCAG AA contrast, with reduced motion respected.
6. **No promises** about search ranking or being cited by AI assistants.
7. **It ships:** type check and production build pass.
