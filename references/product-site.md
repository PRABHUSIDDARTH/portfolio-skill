# Flagship product site mode

A site for one product. It has to answer, in order: what is it, is it for me, does it work, what do I do next. Copy rules are in [portfolio.md](portfolio.md).

## Sections

| Section | Contains | Include when |
| --- | --- | --- |
| Hero | What the product does in plain words, who it is for, one primary action | Always |
| Problem | The situation the visitor recognises | Always |
| Demo | The real product: screenshot, recording or small interactive piece. Label anything simplified as illustrative | Something real exists to show |
| Proof | Real usage numbers, quotes with permission, source code, case studies | Real proof exists |
| Pricing | Actual plans and prices | Pricing is decided |
| FAQ | Questions people really ask, answered directly | Real questions exist or follow from the product's facts |
| Docs link | Where to start using it | Docs or a README exist |

**Omit a section rather than fill it.** No placeholder logos, invented testimonials, made-up counts or "coming soon" prices. For an unreleased product, say it is unreleased and make the action a waitlist or repository link.

## Pages

One page is often enough. Add a page only when it has its own content: pricing, docs, changelog, privacy. A form that collects personal data needs a privacy note.
